## Design Notes

### Emotional Intensity Curve
- **Spring (Mild):** Gentle invitation to awareness, low activation
- **Summer (Medium):** Invitation to feeling, moderate activation
- **Fall (High):** Direct invitation to action, high activation
- **Winter (Reflective):** Integration and meaning-making, contemplative intensity

### Cyclical Deepening (Year 1 → Year 2 → Year 3)
Each prompt can be deepened without changing:
- **Year 1 (surface):** External barrier / what's happening outside you
- **Year 2 (shadow):** Internal pattern / what's happening inside you (the part of you that creates/accepts the barrier)
- **Year 3 (gift):** Integrated resource / how this barrier has taught you something you need

Example: DA-3 "What are you avoiding confronting?"
- **Year 1:** "What external barrier stops me from acting?" (recognizing the obstacle)
- **Year 2:** "What part of me creates this barrier? What's it protecting?" (recognizing internal pattern)
- **Year 3:** "How has my avoidance taught me something? What's the wisdom?" (transforming the barrier into resource)

### Guide Lens Integration
Each prompt is authored with one primary guide in mind, but GMs can enhance with other perspectives:
- **Sage (Gathering Resources):** Wisdom, discernment, long view
- **Diplomat (Skillful Organizing):** Relationship, complexity, bridge-building
- **Challenger (Direct Action):** Honesty, disruption, edge work
- **Shaman (Raising Awareness):** Shadow, transformation, deeper truth

### Worldbuilding Hooks (GM Enhancement)
Each prompt can be contextualized by GMs through 4 domains:
- **Geography:** How does place shape this question?
- **Social:** How does power structure shape this question?
- **History:** How does what came before shape this question?
- **Magic:** How does the threshold/gift/shadow shape this question?
