# 6-Face GM Analysis — Ch0 Token / Ch6 Stakes Lexicon Bleed

**Created:** 2026-05-24  
**Question:** Does Ch0 token economics confuse Ch6 Diplomat identity?  
**Answer:** **Yes — homonym collision.** Same word family, two games.  
**Companion:** `CHANNEL5_RENAME_MAP.md`, `CH6_CHANNEL5_6FACE_ANALYSIS.md`

---

## 🧠 Architect — Lexicon integrity

| Term | Game | Meaning |
|------|------|---------|
| **Token / fuel** (Ch0) | Personal energy economy | Renewable vs non-renewable spend |
| **Ticket** (Ch0) | Internal payout | Return on conscious play |
| **Price / walk-away** (old Ch6) | Relational leverage | Exit terms, cost of presence |

**Fix:** Ch0 → token, fuel, currency, balance. Ch6 → **stakes, terms, interests, sacrifices, agreement**. Avoid **price** in Ch6 negotiator material except explicit gloss.
