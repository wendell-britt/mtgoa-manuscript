## The Three Editing Lenses

### Lens 1 — Source Quality Audit
**Question:** Does every chapter hold its claims against the source texts?

**How it works:** Each chapter makes specific theoretical claims (altitude/color mappings, emotional alchemy mechanics, stage sequences). The Source Quality Audit checks each claim against the 6 source books:

| Source | What It Validates | Key Test Questions |
|--------|------------------|-------------------|
| Laloux / *Reinventing Organizations* | Altitude/color/stage mappings for Green (Pluralistic), Amber (Regent), Teal (Sage) | Does our Green description match Laloux's pluralistic stage? Does our Amber Regent map to Laloux's social order? |
| Wilber / *Integral Life Practice* | AQAL framework, quadrant architecture, all-levels integration | Is our altitude sequence consistent with Wilber's developmental ladder? Does our Sage hold the 6 faces simultaneously as Wilber's Teal does? |
| Yu-kai Chou / *10K HP* | Game mechanics, quest grammar, Octalysis motivation engine | Do our 5 Game moves per chapter match the Octalysis lever design? Does our BARs framing hold against Yu-kai's Core Drive taxonomy? |
| Egan / *The Skilled Helper* | Practice structure, client-centered methodology, developmental teaching | Does our "Practice" section teach the way Egan describes skilled helping — not just concept but reproducible practice? |
| Elliott / *Existential Kink* | Shadow-to-gift framing, "kink as information," embodiment | Does our 8 Gates / Vulnerable Child structure match Elliott's shadow retrieval architecture? Are we doing shadow work or shadow bypass? |
| Igniting Joy (Wendell) | WAVE-Spiral, emotional alchemy, energy economy, personal voice model | Are our Transcend/Translate/Control move labels consistent with the WAVE taxonomy? Does our energy economy (+2/+1/-1) match the book? |

**Output:** Chapter-by-chapter gap list. Each gap tagged:
- `[SOURCE_MISS]` — claim made but not grounded in source
- `[SOURCE_CONF]` — confirmed against source
- `[SOURCE_SKEPTICAL]` — our claim diverges from source; intentional or needs justification

### Lens 2 — Ideal Client Avatar (ICA) Journey Audit
**Question:** Does the reader know where they are at all times, what they're supposed to do, and why it matters to them?

**Why this is separate from source audit:** The source audit checks theoretical accuracy. The ICA journey audit checks whether a specific reader — with specific fears, cravings, and starting points — can actually follow and care about the journey.

**The ICA:**

Name: **Jordan**
- Mid-30s to early 40s
- Has done personal development work (therapy, coaching, workshops)
- Has read books like *Daring Greatly*, *The Body Keeps the Score*, maybe *Reinventing Organizations*
- Has tried to be a better ally — has moments of conviction, moments of paralysis
- **Fear:** "I'm doing more harm than I know."
- **Craving:** "I want to show up for others without losing myself in the process."
- **Starting point:** Knows something is broken in how they show up. Unsure what to do about it.
- **What they skip:** Will skim theory, will not skip a story, will stop for a named move with a practice
- **What triggers drop-off:** Jargon without translation, claims without practice, moralizing without self-deprecation

**The ICA Journey Map (chapter by chapter):**

| Chapter | What Jordan Arrives With | What Jordan Learns | Where Jordan Drops Off (Risk) | What Keeps Jordan Going |
|---------|------------------------|-------------------|------------------------------|------------------------|
| Ch0 Infinite Arcade | Curious but skeptical | The game frame is not trivializing — it's clarifying | If the gamification feels gimmicky | The 6-face ladder promises a real journey, not a gimmick |
| Ch1 Shaman | Overthinking, disconnected from body | Body knows before mind; WAVE-Spiral is the practice | If somatic stuff feels too woo | "Fear is your compass" lands immediately — they've felt this |
| Ch2 Challenger | Fear of being unwelcomed | Moral clarity without cruelty is learnable | If "draw the line" sounds like permission to be harsh | The invitation to draw lines without cruelty is relieving |
| Ch3 Regent | Overwhelmed by systems, "I can't change anything" | Traditions worth protecting + knowing which to break | If Amber feels like a step backward | "Custodian's Index" gives them something concrete to do |
| Ch4 Architect | "I've tried planning, it doesn't work" | Design as love made structural | If Blueprint language feels cold | "Escape is design" reframes their failure as design problem |
| Ch5 Diplomat | "I accommodate, then resent" | Walk-away price makes staying meaningful | If 5 channels feels like more things to do | "The price of your presence" lands viscerally — they've felt this |
| Ch6 Sage | "I can see all the problems, can't act on any" | Panoramic vision without dissociation is possible | If Teal feels like spiritual bypassing | "The Descent Practice" gives altitude a practical ground |
| Ch7 Integration | Some faces developed, others skipped | A map of their own pattern | If self-assessment feels like another self-judgment | BARs promises a practice, not another analysis |

**The ICA Audit Protocol:**
For each chapter, read as Jordan would. Ask:
1. Do I know what I'm supposed to *do* after this chapter?
2. Is there a story or example I can actually picture myself in?
3. Is there a named move I could actually practice this week?
4. Does this chapter respect what I already know (I'm not a beginner)?
5. Does this chapter give me language for what I've been feeling but couldn't name?
6. Does this chapter trigger any defensiveness? (If yes — is it the right shadow material, or is it the author being preachy?)

**Output:** Per-chapter ICA friction list. Each friction tagged:
- `[ICA_CONF]` — Jordan would follow this
- `[ICA_SKIP]` — Jordan skim here
- `[ICA_DROP]` — Jordan stops here
- `[ICA_FLOOR]` — Jordan hits a floor; needs ground-leveling

### Lens 3 — Structural Integrity Check
**Question:** Does each chapter hold the universal template, and do the chapters connect logically?

**Template compliance (each chapter must have):**
- [ ] Opening provocation (1 sentence, Socratic hook)
- [ ] Core thesis stated explicitly
- [ ] Shadow-if-skipped named
- [ ] 3-5 named, practical moves
- [ ] Each move: name + form + what-it-does + how-to-practice + shadow version
- [ ] Shadow scenario (negative example narrative)
- [ ] 8 Gates (face-specific manifestation)
- [ ] BARs prompts (Breakthrough + Action + Reflection)
- [ ] Connecting quest to next face

**Cross-chapter integrity:**
- [ ] Each face's color/altitude consistent across all chapters (verify Ch1-Ch6 alignment)
- [ ] Stage sequence consistent: Bridge → Translate → Hold → Repair → Name Price (Diplomat), Charge → Aim → Act → Exit (Challenger), etc.
- [ ] Emotional alchemy move labels consistent across chapters (Transcend/Translate/Control, +2/+1/-1)
- [ ] 8 Gates sequence consistent (Protector → Controller → Skeptic → Fixer → Fear → Victim → Damaged Self → Vulnerable Child)
- [ ] WAVE-Spiral referenced and practiced in each chapter
- [ ] No altitude/color/name drift between chapters

**Output:** Structural gap list. Each gap tagged:
- `[STRUCTURE_MISS]` — required element absent
- `[STRUCTURE_DRIFT]` — element present but inconsistent with template
- `[CROSS_CHAPTER]` — claim or label that contradicts another chapter

## Editing Phase — Implementation Plan

### Phase 1 — Pre-Work (Before first edit pass)
- [ ] Define Ideal Client Avatar (Jordan) — document in `EDITING_PLAN.md`
- [ ] Create Source Quality Audit rubric — map each source to chapter claims
- [ ] Read all 6 source texts fully before editing (avoid Pattern 2: proceeding without reading)
- [ ] Create chapter comparison matrix: which chapters claim what from which sources

### Phase 2 — Source Quality Audit Pass
- [ ] Run each chapter against Source Quality rubric
- [ ] Tag each claim: [SOURCE_CONF] / [SOURCE_MISS] / [SOURCE_SKEPTICAL]
- [ ] For [SOURCE_SKEPTICAL] claims: decide intentional divergence or fix
- [ ] Produce gap list per chapter

### Phase 3 — ICA Journey Pass
- [ ] Read each chapter as Jordan
- [ ] Apply ICA Audit Protocol (6 questions per chapter)
- [ ] Tag each friction: [ICA_CONF] / [ICA_SKIP] / [ICA_DROP] / [ICA_FLOOR]
- [ ] Produce per-chapter friction list

### Phase 4 — Structural Integrity Pass
- [ ] Verify each chapter against template checklist
- [ ] Cross-reference all chapters for drift (altitude, color, move labels)
- [ ] Check 8 Gates sequence, WAVE-Spiral consistency
- [ ] Produce structural gap list

### Phase 5 — Integration and Fixes
- [ ] Combine all three gap lists into unified priority queue
- [ ] Sort by: severity of reader drop-off risk > theoretical accuracy > structural compliance
- [ ] Edit chapters in priority order
- [ ] Each fix: verify against all three lenses before declaring resolved

### Phase 6 — Beta Reader Preparation
- [ ] Select 3-5 beta readers who match ICA profile
- [ ] Create reader feedback template mapped to ICA journey map
- [ ] Identify which chapters have highest [ICA_DROP] risk for targeted review
- [ ] Set feedback window (2-3 weeks)
- [ ] Plan analysis session post-feedback
