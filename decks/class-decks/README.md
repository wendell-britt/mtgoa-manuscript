# Class Decks

The six superpower classes, each rendered as a draftable card pool. Converted from the original lead-gen strategy guides into the manuscript/deck voice, de-funneled, and re-rooted so each class reads as a **defensive strategy the Protector built** (the survival capacity grown up), turning defensive→offensive across play.

Each deck follows one five-component template:

1. **Basic moves** — core cards, sorted by the four powers (Wake / Clean / Grow / Show)
2. **Emotional Alchemy moves** — the class's home channels (canonical: fear→excitement, anger→triumph, sadness→poignance, joy→expansion, neutrality→peace), with the rest drawn from allies
3. **Subclasses** — the six self-sabotaging beliefs as governors; each locks one specific card, which the book's belief work brings back online
4. **At each Face** — the same capacity re-aimed by altitude (Shaman / Challenger / Regent / Architect / Diplomat / Sage); this is also the per-chapter class thread
5. **Interactions** — which other decks supply what this one lacks (Formula step 3, enroll allies)

The book plants the class (Ch1) and surfaces the subclass/belief (Ch2); these decks are the deliver-side pool the app draws from, where cards unlock at the speed of play. The character sheet a reader assembles across the book is her starting deck.

**Canon-check note:** components 3 (subclass→locked-card) and 4 (Face matrix) are *derived* from the belief-governors and the Face core-questions rather than adapted from the source guides — they compose existing canon, but the specific assignments are where Wendell's intentions should overrule.
