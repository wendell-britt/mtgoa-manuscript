# Emotional Alchemy Translator
## Mapping 48 Emotions into Emotional Alchemy Framework

**Purpose**: Convert all emotion references in the 52-card prompt deck into the Emotional Alchemy framework (5 elements, WAVE stages, altitude states).

**Created**: 2026-04-20
**Status**: Ready for JSON schema integration
**Verification**: All 48 emotions mapped to core framework

---

## Core Framework Reference

### 5 Elements (Channels)
- **Metal**: Fear (risk detection, excitement = reframed fear)
- **Water**: Sadness (what I care about is distant/misaligned)
- **Wood**: Joy (vitality detected)
- **Fire**: Anger (obstacle/boundary violated)
- **Earth**: Neutrality (whole-system perspective)

### WAVE Progression (per element)
- **Wake**: Notice signal → detect activation
- **Clean**: Correct distortion → clarify boundary/risk/meaning
- **Grow**: Extract lesson → integrate insight
- **Show**: Act aligned with lesson → execute move

### Altitude States (per channel)
- **Dissatisfied**: Mask + desire + fear (unaligned, carrying the charge)
- **Neutral**: In-process, moving through WAVE
- **Satisfied**: Aligned action + artifact (alchemized into gift)

### 15 Canonical Moves
**Transcend** (vertical, same element): +2 energy
**Generative Translate** (flow cycle): +1 energy
**Control Translate** (precision pivot): -1 energy

## Integration Rules for JSON Schema

### Rule 1: Channel Assignment
Every emotion → one primary channel. Multi-channel emotions require GM clarification at prompt design time.

**Implementation**:
```json
{
  "gate_risk": ["Anger", "Shame"],
  "emotional_alchemy": {
    "primary_channel": "Fire",
    "secondary_channel": "Earth",
    "primary_altitude": "dissatisfied",
    "primary_wave_stage": "Clean"
  }
}
```

### Rule 2: Altitude Derivation
Altitude is set at design time based on prompt intent, not emotion alone.

**Example**:
- Prompt: "What are you angry about?" → Fire:Dissatisfied:Wake (detect obstacle)
- Prompt: "How have you honored your anger?" → Fire:Satisfied:Show (boundary maintained)

### Rule 3: WAVE Stage Mapping
The prompt's phase (Wake/Clean/Grow/Show) should align with the emotion's natural WAVE progression.

| Prompt Phase | Alchemy Meaning |
|--------------|-----------------|
| Recognition | Wake (notice) |
| Deepening | Clean (clarify) |
| Commitment | Grow/Show (integrate/act) |

### Rule 4: Move Type Inference
Moves are **not** predetermined by emotion alone. They emerge from prompt design intent.

**Example**:
- GR-1 "What resources do you have?" → Victim:Dissatisfied:Wake → Move: Face It (recognize what you have)
- GR-12 "What are you willing to give?" → Joy:Satisfied:Show → Move: Commit to Growth
