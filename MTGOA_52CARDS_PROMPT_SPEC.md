## Core Design Principle

Each of the 52 prompts must:
1. **Stand alone** - work in isolation (player draws card without context)
2. **Contextualize** - work with GM's worldbuilding (same prompt, different world, different meaning)
3. **Cycle** - work across multiple years (Year 1 = learning, Year 2+ = deepening)
4. **Gate-activate** - implicitly invite the reader to notice their protective patterns
5. **Scale** - work for both solo players and group facilitation
6. **Sustain** - generate a practice rule the player can commit to

### Back of Card (Where Player Writes)

```

```

## Quality Criteria for Each Prompt (9-Point Verification)

Every prompt must pass these checks:

### 1. CLARITY
- **Criterion:** Prompt is immediately understandable on first read (no jargon, unless defined in book)
- **Verification:** Can a first-time reader understand what action/reflection is being asked?
- **Fail indicator:** Prompt requires more than 2 readings to parse

### 2. ACTIONABILITY
- **Criterion:** Prompt invites observable action or naming, not vague reflection
- **Verification:** Does prompt ask for something the player can do THIS WEEK?
- **Fail indicator:** Prompt is purely theoretical ("what do you think about allyship?")

### 3. EMOTIONAL INTENSITY
- **Criterion:** Prompt creates just enough emotional charge to shift something
- **Verification:** Does prompt land in the emotional channel for its season?
  - Spring (Wake): Recognition, curiosity, mild urgency
  - Summer (Grow): Excitement, expansion, some tension
  - Fall (Show): Fear, grief, necessary discomfort
  - Winter (Clean): Peace, wisdom, integration
- **Fail indicator:** Prompt is too gentle (doesn't activate) or too harsh (shuts down)

### 4. GATE-RESONANCE
- **Criterion:** Prompt implicitly invites a specific gate pattern to surface
- **Verification:** Which gate does this prompt naturally activate?
  - Spring/Gathering: Often surfaces Protector (resource anxiety) or Skeptic (doubt)
  - Summer/Organizing: Often surfaces Controller (need to manage) or Victim (powerlessness)
  - Fall/Action: Often surfaces Fear, Victim, or Damaged Self
  - Winter/Awareness: Often surfaces Vulnerable Child (saying what's true) or Fixer (what didn't work)
- **Fail indicator:** Prompt doesn't activate any recognizable gate pattern

### 5. CONTEXTUALITY
- **Criterion:** Prompt works BOTH standalone AND with GM's worldbuilding context
- **Verification:**
  - Can player answer it with no world context? (Yes)
  - Can GM enhance it using Geography/Social/History/Magic? (Yes)
- **Fail indicator:** Prompt only works in one mode (too generic, or too world-dependent)

### 6. CYCLICAL DEPTH
- **Criterion:** Prompt deepens with replay (Year 2 answer is different from Year 1)
- **Verification:** Could a player answer this 3 times (Years 1/2/3) with increasingly nuanced responses?
- **Fail indicator:** Prompt is exhausted after first answer (no deeper layer emerges on replay)

### 7. BAR-ALIGNMENT
- **Criterion:** Prompt naturally generates all 4 BAR phases
- **Verification:** Can player fill Breakthrough → Action → Reflection → Sustain from this prompt?
- **Fail indicator:** Prompt only generates one or two BAR phases (e.g., only Reflection, no Action)

### 8. TONE-CONSISTENCY
- **Criterion:** Prompt matches the voice/tone of the domain + season
- **Verification:**
  - Gathering prompts: Curious, establishing, grounded
  - Organizing prompts: Connective, collaborative, process-focused
  - Action prompts: Honest, courageous, confronting
  - Awareness prompts: Generous, teaching, reflective
- **Fail indicator:** Prompt voice doesn't match domain (e.g., commanding tone in Gathering domain)

### 9. REPLAYABILITY
- **Criterion:** Prompt invites different answers each cycle (not exhausted)
- **Verification:** Are there at least 3 different legitimate answers to this prompt?
- **Fail indicator:** Prompt has ONE "right" answer or exhausts itself after first response

## Design Constraints & Requirements

### Structural Constraints

- **Length:** Each prompt title 1-3 words, primary question 1-2 sentences, secondary 1-2 sentences
- **Jargon:** Avoid technical language (no "activate your Victim gate" — instead "notice the helplessness pattern")
- **Sequencing:** Within each domain (Hearts/Diamonds/Clubs/Spades), prompts should build toward coherence
  - Early cards (1-5): Establish, ground, clarify
  - Middle cards (6-9): Deepen, process, confront
  - Late cards (10-13): Integrate, teach, reflect

### Domain-Specific Constraints

**Spring / Gathering Resources (Hearts 1-13)**
- Focus on recognizing, naming, establishing what exists
- Tone: Curiosity, clarity, grounding
- Gate work: Surfacing Protector anxiety + Skeptic doubt

**Summer / Skillful Organizing (Diamonds 14-26)**
- Focus on coordination, relationship, process
- Tone: Connection, emergence, collaborative
- Gate work: Surfacing Controller need + Victim powerlessness

**Fall / Direct Action (Clubs 27-39)**
- Focus on confrontation, courage, moving despite fear
- Tone: Honesty, courage, discomfort
- Gate work: Surfacing Fear, Victim, Damaged Self patterns

**Winter / Raising Awareness (Spades 40-52)**
- Focus on reflection, teaching, legacy, integration
- Tone: Wisdom, generosity, completion
- Gate work: Surfacing Vulnerable Child truth-telling + Fixer learning

### Temporal Constraint

- Prompts must work for **52-week cycles**
- Same prompt, different seasons of the campaign, different answers
- Expect Year 1 → Year 2 → Year 3 deepening (not repetition)

## Integration with Other Systems

### Connection to GM Toolkit

Each prompt should be **contextualizable** by GM using Foundations domains:

**Example Enhancement:**
- **Base prompt:** "What barrier are you avoiding?" (7 of Clubs)
- **With Geography context:** "What barrier does the landscape create? How far do people have to travel to act?"
- **With Social context:** "What barrier does the power structure create? Who could be retaliated against?"
- **With History context:** "What barrier comes from what happened before? What failure are you protecting against?"
- **With Magic context:** "What barrier is actually a threshold? What's on the other side of this fear?"

### Connection to BAR Cards

Each prompt should naturally generate:
- **Breakthrough:** Recognition of something new (signal)
- **Action:** Something the player does this week (observable move)
- **Reflection:** What changed when they moved (evidence)
- **Sustain:** The practice rule they commit to (weekly habit)

## Examples of Strong vs Weak Prompts

### WEAK PROMPT (Fails on clarity + actionability + cyclical depth)
```
Title: "Allyship Reflection"
Question: "What does allyship mean to you?"

Problems:
- Too vague (what does "mean" entail?)
- No gate activation
- One answer exhausts it (philosophical question)
- No BAR connection (only Reflection)
```

### STRONG PROMPT (Passes all 9 criteria)
```
Title: "The Abundance"
Question: "What do you already have that you haven't counted as a resource?"
Secondary: "Who have you learned from that you haven't named as a teacher?"

Strengths:
- Clear action (count what exists, name teachers)
- Emotional intensity: Recognition + shame at what's been invisible
- Gate: Activates Protector (didn't notice what protects) + Skeptic (doubt we're worthy)
- Actionable: Can write a list, can reach out to teacher
- Contextualizable: GM can ask "what about your place's history shows hidden resources?"
- Cyclical: Year 1 = external resources/people, Year 2 = internal capacities, Year 3 = systematic resources
- BAR-aligned: BT (recognition), A (contact someone), R (what shifted), S (weekly: name one teacher)
- Replayable: 3+ different legitimate answers across cycles
```

Each prompt has a version history and stability indicator.

### Versioning Schema

```json
{
  "card_id": "clubs_07",
  "current_version": "1.0",
  "versions": [
    {
      "version": "1.0",
      "created_date": "2026-04-20",
      "created_by": "claude",
      "prompt_text": "What are you avoiding confronting?",
      "status": "approved",
      "change_reason": "initial_creation"
    },
    {
      "version": "1.1",
      "created_date": "2026-05-15",
      "created_by": "wendell",
      "prompt_text": "What are you avoiding confronting? What would change if you moved anyway?",
      "status": "approved",
      "change_reason": "clarified_secondary_question",
      "change_impact": "minor"
    }
  ],
  "stability": "stable",
  "locked": false,
  "deprecation_notice": null
}
```

### Stability Levels

- **stable** - Locked in, won't change. Safe for long-term player use.
- **experimental** - Testing new version. May be revised. Caveat: "Results may vary."
- **deprecated** - Replaced by better version. Retiring this prompt.

### When to Lock a Prompt

Lock a prompt after:
- Multiple cycles of player use
- Consistent positive feedback on clarity and impact
- Verified against all 9 quality criteria
- Used by 10+ players across 2+ campaigns

## Section 8: PROMPT VARIATIONS BY CYCLE

Each prompt has variations for Year 1, Year 2, and Year 3+ to support deepening.

### Why Variations?

Same prompt repeated 3 times in same form exhausts itself. But same prompt *with depth variations* invites continuous learning.

### Variation Strategy

```json
{
  "card_id": "clubs_07",
  "prompt_variations": {
    "year_1_surface": {
      "title": "The Barrier",
      "primary": "What are you avoiding confronting?",
      "secondary": "What would change if you moved anyway?",
      "depth_level": "surface",
      "target_gate": ["Victim", "Fear"],
      "guidance": "First time: Name the external barrier. What's in the way?",
      "expected_answer_type": "external_obstacle"
    },
    "year_2_shadow": {
      "title": "The Barrier",
      "primary": "What part of you feels powerless here? What's it protecting?",
      "secondary": "What would it mean to acknowledge that powerlessness instead of avoiding it?",
      "depth_level": "shadow",
      "target_gate": ["Victim"],
      "guidance": "Second time: Go inward. What pattern does this activate in you? What's the protective strategy?",
      "expected_answer_type": "internal_pattern",
      "note": "Year 2: Invite the Victim gate to speak. What is it trying to protect?"
    },
    "year_3_gift": {
      "title": "The Barrier",
      "primary": "What has your avoidance taught you? What wisdom is in that protection?",
      "secondary": "How could that protective strategy become a resource?",
      "depth_level": "gift",
      "target_gate": ["Victim"],
      "guidance": "Third time: Integration. What has this pattern given you? What's the gift?",
      "expected_answer_type": "internal_resource",
      "note": "Year 3: Transform the shadow into strength. What did the Victim gate protect?"
    }
  }
}
```

### Deepening Arc Example

**CARD: 7 of Clubs**

Year 1 (Surface):
```
Q: "What are you avoiding confronting?"
A: "I'm avoiding confronting my workplace's racism. It feels overwhelming."
→ BAR: Breakthrough (it's racism, not just a personality issue)
        Action (I asked three POC colleagues for perspective)
        Reflection (They've been carrying this alone; I wasn't seeing it)
        Sustain (I will listen before offering solutions)
```

Year 2 (Shadow):
```
Q: "What part of you feels powerless here? What's it protecting?"
A: "My Victim part believes I can't make real change. It protects me from taking risks."
→ BAR: Breakthrough (my helplessness is a choice, not a fact)
        Action (I stayed in a difficult conversation instead of leaving)
        Reflection (The powerlessness comes from ME, not the system)
        Sustain (When I feel helpless, I ask: What am I actually afraid of?)
```

Year 3 (Gift):
```
Q: "What has your avoidance taught you? How is that a strength?"
A: "My avoidance taught me to listen first. That's why people trust me. My hesitation is my care."
→ BAR: Breakthrough (my caution is a gift, not a flaw)
        Action (I co-led a listening session with the team)
        Reflection (By honoring my care, others felt safe speaking)
        Sustain (I use my deliberation as a tool for deeper work)
```

**Notice:** Same card, same core question, but progressively deeper and more generative.

## Section 9: DEEPENING PRINCIPLES

What makes a prompt support cyclical learning (not just repetition)?

### Principle 1: Multiple Legitimate Answers

A prompt deepens if it can be answered 3+ different ways across cycles.

```
GOOD (supports deepening):
  Q: "What barrier are you avoiding?"
  Year 1: External barrier (workplace racism)
  Year 2: Internal barrier (my own helplessness)
  Year 3: Systemic barrier (how my avoidance replicates the system)
  ✓ Three different legitimate answers, each deeper

BAD (exhausted after first answer):
  Q: "How much time did you spend this week?"
  Year 1: "15 hours"
  Year 2: "Still 15 hours" (same answer, nothing new)
  ✗ Exhausted, no deepening
```

### Principle 2: Reveals Layers

A deepening prompt reveals new layers, not just "harder" answers.

```
LAYERING (external → internal → systemic):
  Barrier (external layer): "The workplace culture makes it unsafe"
  ↓ deepen
  Barrier (internal layer): "My Victim part doesn't believe I can change anything"
  ↓ deepen
  Barrier (systemic layer): "By staying quiet, I'm maintaining the system I'm criticizing"

Each layer is true. Each year, player discovers the next layer.
```

### Principle 3: Supports Continuous Growth

A deepening prompt stays relevant as the player grows.

```
RELEVANT ACROSS GROWTH:
  Q: "What's your greatest resource?"
  Beginner answer: "My time, my energy"
  Intermediate answer: "My relationships, my position"
  Advanced answer: "My capacity to hold complexity and my willingness to be changed by this work"

Same question, but player's understanding of "resource" deepens.
```

### Principle 4: Informs the Next Cycle

A deepening prompt's answer becomes the starting point for next year's work.

```
CYCLICAL CHAIN:
  Year 1: "What barrier are you avoiding?" → Answer: My own helplessness
  Year 2: "What part of you feels powerless?" → Answer: My Victim gate, protecting me
  Year 3: "How is that protection a strength?" → Answer: My care, my listening
  ↓
  Year 4 (if continued): That listening/care becomes the focus of the next year's work
```

### Deepening Verification Checklist

For each prompt, verify:

```
□ Can be answered 3+ different ways (external → internal → systemic, or beginner → advanced)
□ Reveals layers (not just "harder" answers)
□ Stays relevant across growth stages
□ Answer informs next cycle
□ Player can reference last year's answer ("I see now that...")
□ Prompt becomes MORE interesting with each replay, not exhausted
```
