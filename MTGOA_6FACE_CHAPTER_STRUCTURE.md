## Core Design Principle

Each chapter teaches one Face of the Game Master. The chapter must function at TWO levels:
1. **Teaching the level's tools and moves** — what the player gets
2. **Demonstrating the level's shadow** — what happens when you skip or overuse it

The 6-face arc mirrors the Integral AQAL developmental ladder:
Magenta (survival) → Red (socialized power) → Amber (social order) → Orange (strategic) → Green (relational) → Teal (integrative)

Every Face chapter follows this structure:

```
CHAPTER N: [FACE NAME] — [Color] — [Altitude]

## Opening Provocation
One sentence that wakes up the reader's felt sense at this altitude.
Must be a Socratic hook — answers "why should I care about this level?"

## The Thesis
What this level teaches, why it matters, what the shadow is if skipped.
Must reference the 6-face thesis: skipping this level = shadow that blocks you.

## Face-Specific Moves (3-5 moves)
Named tools with:
- Name (evocative, memorable)
- Form (what type of move it is — e.g. "Shaman Form", "Challenger Form")
- What it does (one sentence)
- How to practice it (short exercise or prompt)
- The shadow version (what it looks like when misused/skipped)

## The Shadow Demonstration
A narrative scenario showing a character who:
- Overshot this level (used it at the wrong altitude), OR
- Skipped this level and is now blocked by its shadow, OR
- Uses this level's tools but lacks the one below (missing the foundation)

## BARs Refection Prompts (3 prompts)
- One for Breakthrough
- One for Action
- One for Reflection

## Connecting Quest
A quest that bridges this Face to the next Face. 
Must name: what the player takes with them, what they're leaving behind.

## The 8 Gates at This Face — how each gate shows up for this altitude
How do the 8 Gates manifest at this altitude?
Each face experiences the 8 Gates differently — the SAME gate reads differently
at Shaman level vs. Sage level.

## Repeatability Standard

Every chapter MUST:
1. State the thesis for its Face explicitly
2. Name the shadow if skipped
3. Provide 3-5 named, PRACTICAL moves (not just concepts)
4. Include a shadow scenario (negative example)
5. Include 3 BARs prompts
6. Include a connecting bridge to the next Face
7. Include The Forest framing — where does this Face sit in the Village/Forest/Village structure?

Every chapter MUST NOT:
- Assume the reader has read previous chapters (each stands alone enough to teach)
- Use a Face's language without defining it (no jargon without translation)
- Teach a move without a practice (theory without application is decoration)
- Confuse The Forest's 8 Gates with emotional channels — they are different systems

## The Forest — Where Each Face Lives

The Forest framework provides the inner journey structure for the book:

```
VILLAGE → FOREST → VILLAGE

Village = Clean Up + Show Up
Forest = Wake Up + Grow Up

The 8 Gates = The 8 Voices encountered in the Forest:
1. Protector
2. Controller
3. Skeptic
4. Fixer
5. Emotion (5 channels: Fear, Anger, Sadness, Joy, Neutrality — live HERE)
6. Victim
7. Damaged Self
8. Vulnerable Child ← source of the superpower
```

The Vulnerable Child is the source. The other 7 gates are what you walk through to find it.
