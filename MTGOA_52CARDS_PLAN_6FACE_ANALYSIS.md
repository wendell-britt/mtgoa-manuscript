# 6-Face Analysis: MTGOA 52-Card Design Questions
## Evaluating Guide Lens, Emotional Channels, Player Context, & Facilitation Detail

**Date:** 2026-04-20
**Scope:** 6 Game Master analysis of 4 open design questions

---

## Question 1: Guide Lens Attribution

**THE QUESTION:** Should each prompt reference a specific guide (Shaman, Challenger, etc.)? Should every domain have a primary guide lens, or should guides vary across the 52 cards?

---

### 🧠 ARCHITECT — Structural Logic

**Assessment:**
Having a consistent guide per domain creates clarity. Having mixed guides creates flexibility.

**TAKE:**
- **Consistent approach (one guide per domain):**
  - Gathering (Spring/Hearts) → Sage (wisdom, grounding, practice)
  - Organizing (Summer/Diamonds) → Diplomat (bridge, harmony, connection)
  - Action (Fall/Clubs) → Challenger (critical edge, honesty, confrontation)
  - Awareness (Winter/Spades) → Shaman (integration, shadow, wisdom)

**LEAVE:**
- Don't randomly assign guides (creates confusion)
- Don't let guides get lost (they're too useful to ignore)

**RECOMMENDATION:**
**Assign one primary guide per domain.** This creates:
- Coherent lens across 13 cards
- Player recognizes the domain's voice
- GM knows which guide's toolkit to use
- Architectural clarity

---

### 🏛 REGENT — Elegant Preservation

**Assessment:**
Consistent guides preserve the integrity of each domain. Varying guides fragments.

**TAKE:**
- Consistency (same guide for all 13 cards in domain)
- Preservation of guide identity (each guide has a clear voice)
- Player learning (player learns "Gathering is Sage's domain")

**LEAVE:**
- Don't mix guides within a domain (loses coherence)
- Don't let secondary guides disappear from the deck

**RECOMMENDATION:**
**Primary guide per domain + optional secondary guide per card.**

Example:
```
Gathering cards (Hearts 1-13):
  Primary guide: Sage (for all 13)
  Secondary guides vary: Sage+Architect (heart_02), Sage+Regent (hearts_05), etc.

This way:
- Coherence is preserved (Sage is consistent)
- Flexibility exists (secondary guides add nuance)
- Each card has a primary + secondary lens
```

---

### ⚔️ CHALLENGER — Critical Edge

**Assessment:**
If a guide is assigned, the prompt needs to prove it. Empty assignments are worse than no assignment.

**TAKE:**
- **Don't assign unless the guide is active in the prompt**
  - If the prompt activates Challenger's edge, name it
  - If the prompt is just using Sage wisdom, don't call in Challenger
- Verification: Can you explain WHY this guide is assigned?

**LEAVE:**
- Don't assign guides as decoration
- Don't add guides to meet a quota ("we need all 6 guides!")

**RECOMMENDATION:**
**Assign only if the guide's work is visible in the prompt.**

For example:
- "What barrier are you avoiding confronting?" (Fall/Clubs) = Challenger visible (calling out avoidance)
- "What's your greatest resource?" (Spring/Hearts) = Sage visible (wisdom, grounding)
- "How do you share power?" (Summer/Diamonds) = Diplomat visible (harmony, bridge)

If you can't explain it, don't assign it.

---

### 🎭 DIPLOMAT — Bridge & Harmonize

**Assessment:**
Guides are bridges between the book and the engine. If assigned, they should help players understand the work better.

**TAKE:**
- **Guides help players recognize what work they're doing**
  - "Oh, this is Challenger work (confronting avoidance)"
  - "Oh, this is Sage work (grounding in what exists)"
- Guides bridge book chapters → card questions
- Players who read the book recognize the guide's voice

**LEAVE:**
- Don't assign guides that don't connect to the chapter
- Don't use guides to fill gaps

**RECOMMENDATION:**
**Name the guide in the card front (player-facing side).**

Format:
```
7 of Clubs — Fall
THE BARRIER
What are you avoiding confronting?
What would change if you moved anyway?

Challenger: Call it out
Watch for: Victim pattern
```

Why:
- Players read the chapter, recognize Challenger's voice in the prompt
- GM can reference the chapter for context
- Guides create coherence between book and deck

---

### 🌊 SHAMAN — Shadow & Metaphysics

**Assessment:**
Different guides activate different shadow patterns. Assigning the right guide makes shadow work explicit.

**TAKE:**
- **Guide assignment reveals what shadow work is happening**
  - Sage prompts invite Vulnerable Child (speak truth, grounded wisdom)
  - Challenger prompts invite Fear/Damaged Self (courage, confrontation)
  - Diplomat prompts invite Victim (powerlessness in relationship)
  - Shaman prompts invite Fixer (learning, integration)

**LEAVE:**
- Don't use guides to hide shadow work
- Don't assign guides that mask the pattern

**RECOMMENDATION:**
**Guide assignment should align with gate activation.**

Pattern:
```
Gathering (Sage) → Protector/Skeptic gates → "What exists? What's true?"
Organizing (Diplomat) → Controller/Victim gates → "How do we relate? Where's power?"
Action (Challenger) → Fear/Damaged Self gates → "What are we avoiding? What courage?"
Awareness (Shaman) → Vulnerable Child/Fixer gates → "What did we learn? What's the gift?"
```

Guides make the shadow work intentional and named.

---

### 📖 SAGE — Timeless Principle

**Assessment:**
"Practice over theory" means guides should be useful to players, not just labels.

**TAKE:**
- **Guides should help players practice the work of the moment**
  - Sage guide helps practice grounding, wisdom, presence
  - Challenger guide helps practice courage, confrontation, honesty
  - Diplomat guide helps practice bridge-building, harmony
  - Shaman guide helps practice integration, shadow work

**LEAVE:**
- Don't assign guides that don't teach practice
- Don't use guides as theory (they're tools, not concepts)

**RECOMMENDATION:**
**One guide per domain, with optional secondary.**

This way:
- Each domain has a clear practice (Sage's practice, Challenger's practice, etc.)
- Players learn to embody the guide's work
- Over 52 weeks, players practice 4 guides deeply (1 per domain)
- Secondary guides add nuance without overwhelming

---

## Summary: Guide Lens Question

**✅ RECOMMENDED APPROACH:**

**One primary guide per domain:**
- Gathering/Spring → Sage
- Organizing/Summer → Diplomat
- Action/Fall → Challenger
- Awareness/Winter → Shaman

**Optional secondary guides per card** (add nuance, not confusion)

**Why this works:**
- Architectural clarity (one guide per domain)
- Preservation of guide integrity (consistent voice)
- Challenge validation (only assign if active in prompt)
- Bridge between book and deck (players recognize guide voice)
- Shadow work intentionality (guide aligns with gate)
- Practice utility (guides help players do the work)

## Question 2: Emotional Channels Integration

**THE QUESTION:** Should prompts explicitly reference the 5 emotional channels (Fear, Sadness, Anger, Joy, Shame)? Should each prompt activate one primary channel?

---

### 🧠 ARCHITECT — Structural Logic

**Assessment:**
The 5 emotional channels are part of the book (Chapter 1 mentions them). Should they be visible in the deck?

**TAKE:**
- **Channels create a second layer of organization**
  - Currently: 4 domains × 13 cards
  - With channels: 4 domains × 13 cards × activates one of 5 channels
- This gives players a map of "emotional terrain" (not just strategic terrain)

**LEAVE:**
- Don't create confusion between gates and channels
- Gates = protective patterns (Victim, Protector, Fear, etc.)
- Channels = emotional weather (Anger, Sadness, Fear, Joy, Shame)
- These are different systems

**RECOMMENDATION:**
**Include channel activation, but don't name it on the front of the card.**

Instead:
- Include in the metadata/backend (game engine knows which channel)
- Let players discover the pattern through repeated play (Year 1 → Year 2 → Year 3)
- GM can reference channels if facilitating group work

---

### 🏛 REGENT — Elegant Preservation

**Assessment:**
The book names the 5 channels as useful distinctions. The deck should preserve this structure without cluttering the player interface.

**TAKE:**
- Channels are useful for GMs (helps them understand what's being activated)
- Channels are useful for game engine (can track emotional terrain across campaigns)
- Channels are useful for players over time (recognizing patterns)

**LEAVE:**
- Don't clutter the card front with channel names
- Don't teach channels through the deck (they're in the book)

**RECOMMENDATION:**
**Include in JSON metadata, not on player-facing side.**

```json
{
  "card_id": "clubs_07",
  "prompt": {
    "title": "The Barrier",
    "primary_question": "What are you avoiding confronting?",
    "emotional_channel": "Fear"  // ← included for GM/engine
  }
}
```

Player sees: Title + question (clean, simple)
GM sees: Card + "activates Fear channel" (useful context)
Engine tracks: Fear channel activated in Fall/Action domain

---

### ⚔️ CHALLENGER — Critical Edge

**Assessment:**
Can you prove that each prompt activates one primary channel? Or would you be forcing the mapping?

**TAKE:**
- **Only assign a channel if it's genuinely the primary emotional activation**
- Don't assign channels to fill a quota
- Different players might activate different channels from same prompt

**LEAVE:**
- Don't assume one channel per card (it might vary by player)
- Don't make channel assignment a burden

**RECOMMENDATION:**
**Design for the most likely channel activation, but stay flexible.**

Example:
```
"What barrier are you avoiding confronting?" (Fall/Clubs)
→ Primary channel: Fear (courage needed to move)
→ Secondary channel: Anger (at being in this position)
→ Tertiary channel: Sadness (grief at the barrier)

But different players might activate different channels.
That's OK. GMs can note what actually activated.
```

---

### 🎭 DIPLOMAT — Bridge & Harmonize

**Assessment:**
Channels help players and GMs recognize what emotional weather is present. Should this be explicit (on card) or implicit (in metadata)?

**TAKE:**
- **Make it available to GMs, invisible to players on first read**
- Players learn channels in the book (Chapter 1)
- Players discover their channel patterns through play (Year 1 → Year 2)
- GMs can reference channels in facilitation ("What emotional channel is this activating for you?")

**LEAVE:**
- Don't teach channels through the deck
- Don't overwhelm players with too much metadata

**RECOMMENDATION:**
**Channels in metadata, available to GMs but not forced on players.**

GM facilitation might include:
```
"This card activates the Fear channel. What does Fear want you to know?"
or
"Notice what emotional channel is activated for you. Sadness? Anger? Fear?"
```

This bridges the book (where channels are taught) and the deck (where they're experienced).

---

### 🌊 SHAMAN — Shadow & Metaphysics

**Assessment:**
Channels are emotional weather. Shadow gates are protective patterns. How do they relate?

**TAKE:**
- **Channels + gates together reveal the full shadow landscape**
  - Gate (protective pattern) + Channel (emotional weather) = full picture
  - "I have a Victim gate (protecting me from risk) + Fear channel (what's the danger?)"

**LEAVE:**
- Don't confuse channels with gates
- Don't reduce shadow to just one system

**RECOMMENDATION:**
**Map channels to gates for shadow clarity.**

Pattern:
```
Gate patterns + Channel activations:

Protector gate + Fear channel = "What am I protecting?"
Skeptic gate + Shame channel = "What am I doubting about myself?"
Controller gate + Anger channel = "What can't I control?"
Victim gate + Sadness channel = "What loss am I carrying?"
Fear gate + Sadness channel = "What catastrophe am I expecting?"
Fixer gate + Anger channel = "What can't I fix?"
Damaged Self gate + Shame channel = "What's broken in me?"
Vulnerable Child gate + Joy channel = "What truth wants to be born?"
```

This gives players a map of "what pattern am I in + what emotional weather am I experiencing?"

---

### 📖 SAGE — Timeless Principle

**Assessment:**
Practice over theory: Should players *learn* channels through the deck, or *discover* them through play?

**TAKE:**
- **Players learn channels in the book (theory)**
- **Players discover channel patterns through play (practice)**
- The deck is practice, not teaching

**LEAVE:**
- Don't use the deck to re-teach channels
- Don't make channels a required knowledge

**RECOMMENDATION:**
**Channels in metadata, discovered through play, available for GM reference.**

This way:
- Players who read the book recognize channels as they play
- Players who didn't read the book can discover channels through GM facilitation
- GMs have the data to help players understand their patterns
- The deck becomes a practice tool, not a teaching tool

---

## Summary: Emotional Channels Question

**✅ RECOMMENDED APPROACH:**

**Include channels in JSON metadata, not on player-facing card.**

```json
{
  "emotional_channel": "Fear" // (or Sadness, Anger, Joy, Shame)
}
```

**Why:**
- Architectural clarity (one primary channel per card)
- Player simplicity (doesn't clutter the front of the card)
- GM utility (helps facilitate shadow work)
- Engine tracking (can track emotional terrain across campaigns)
- Practice-first approach (players discover through play, not taught)

**Channel assignment validates:**
✓ Does this prompt activate one primary emotional channel?
✓ Does it align with the domain? (Action = Fear, Awareness = Sadness, etc.)
✓ Does the GM toolkit reference it?

## Question 3: Player Context Integration (Year-to-Year)

**THE QUESTION:** When a player replays a card in Year 2, should they see their Year 1 answer? Should GM have access to player history?

---

### 🧠 ARCHITECT — Structural Logic

**Assessment:**
Cyclical deepening requires context. Does that context come from the card itself or from system memory?

**TAKE:**
- **YES, show Year 1 answers when replaying**
  - "Last year you said: ___. What's different now?"
  - Creates visible progression (especially valuable in shadow work)
- Year 1 → Year 2 deepening is more meaningful with context

**LEAVE:**
- Don't force players to remember (provide the memory)
- Don't hide progress (show evolution)

**RECOMMENDATION:**
**Store all BAR card responses + create "evolution view" for replay.**

On the Year 2 replay:
```
7 of Clubs — Fall (Year 2)
THE BARRIER

LAST YEAR YOU SAID:
"I'm avoiding confronting my workplace's racism. It feels overwhelming."
→ Breakthrough: it's racism, not just a personality issue
→ Action: I asked three POC colleagues for perspective

THIS YEAR:
What part of you feels powerless here? What's it protecting?
[blank space for new response]
```

---

### 🏛 REGENT — Elegant Preservation

**Assessment:**
Previous responses are artifacts of the player's practice. They should be preserved and visible.

**TAKE:**
- **Every BAR card response gets stored**
  - Date stamp (when was this written?)
  - Versioning (if revised, preserve original)
  - Visible history (player sees their evolution)

**LEAVE:**
- Don't delete old responses
- Don't hide progress

**RECOMMENDATION:**
**Full history on every card, with clear "Year 1 | Year 2 | Year 3" tabs.**

Example card layout:
```
┌─────────────────────────────────────┐
│ YEAR 1 | YEAR 2 | YEAR 3          │
├─────────────────────────────────────┤
│ YEAR 2 TAB SELECTED:                │
│                                     │
│ PREVIOUS ANSWER (Year 1):           │
│ "I'm avoiding confronting racism.   │
│  It feels overwhelming."            │
│                                     │
│ THIS YEAR'S QUESTION:               │
│ "What part of you feels powerless?" │
│ [blank space for Year 2 response]   │
└─────────────────────────────────────┘
```

---

### ⚔️ CHALLENGER — Critical Edge

**Assessment:**
Will showing previous answers encourage deepening or just rehashing?

**TAKE:**
- **Context encourages genuine deepening, not repetition**
- "Last year you said: external barrier. What about internal?"
- Prevents circular answers (Year 2 = same as Year 1)

**LEAVE:**
- Don't assume showing answers will help (context matters)
- Don't let players just copy-paste

**RECOMMENDATION:**
**Show Year 1 answer + different prompt for Year 2.**

This prevents:
- Circular repeating (same answer each year)
- Shallow deepening (just harder version of same answer)
- Rote compliance (I already answered this)

Forces:
- Genuine progression (what's new?)
- Shadow work (go inward, go systemic)
- Accountability (player sees their growth)

---

### 🎭 DIPLOMAT — Bridge & Harmonize

**Assessment:**
GMs need context to facilitate effectively. Should they see player history?

**TAKE:**
- **YES, GMs should have access to player history**
  - Helps GM understand this player's pattern
  - Helps GM facilitate the deepening
  - Creates continuity across years

**LEAVE:**
- Don't expose player history to other players (privacy)
- Don't use history punitively ("you said this last year!")

**RECOMMENDATION:**
**GM sees player history in GM interface, not shared with group.**

GM facilitation with context:
```
Player draws 7 of Clubs (Year 2)
GM sees in backend:
  - Year 1 answer: External (racism in workplace)
  - Year 1 BAR: Breakthrough, Action, Reflection, Sustain
  - Pattern: This player struggles with Victim gate, tends toward external answers

GM facilitates with context:
  "Last year you recognized the external barrier. This year the question goes inward.
   What part of you feels powerless in this situation? What's that protecting?"

This bridges Year 1 → Year 2 and helps player go deeper.
```

---

### 🌊 SHAMAN — Shadow & Metaphysics

**Assessment:**
Shadow work deepens across years. Player history is essential for tracking transformation.

**TAKE:**
- **History shows shadow transformation (Year 1 surface → Year 2 shadow → Year 3 gift)**
- "Last year you named the external barrier. This year you name the internal pattern."
- "Last year you said your Victim part protects you from risk. This year: how is that protection a strength?"

**LEAVE:**
- Don't hide the transformation
- Don't force players to re-do work

**RECOMMENDATION:**
**Full history visible to player + GM, with clear transformation arc shown.**

Transformation example visible on card:
```
YEAR 1: "I'm avoiding confronting my workplace's racism."
  Gate activated: Victim (feels powerless)

YEAR 2: "My Victim part believes I can't make real change."
  Gate deepened: Victim (reveals protective function)

YEAR 3: "My avoidance taught me to listen first."
  Gate transformed: Victim → Gift (listening, care)

Player sees: "I went from naming the external barrier, to naming my internal pattern,
            to finding the gift in that pattern."
```

---

### 📖 SAGE — Timeless Principle

**Assessment:**
Mastery is built through repeated practice with deepening understanding. History is evidence of mastery.

**TAKE:**
- **Player sees their own mastery progression**
  - Year 1: "I recognized the barrier"
  - Year 2: "I recognized the pattern"
  - Year 3: "I recognized the gift"
  - This is visible, provable mastery

**LEAVE:**
- Don't hide progress
- Don't make players repeat work they've already done

**RECOMMENDATION:**
**Full history visible, with "mastery markers" showing depth progression.**

Example:
```
MASTERY PROGRESSION (visible to player):
  ✓ Year 1: Surface recognition (external)
  ✓ Year 2: Shadow work (internal)
  ✓ Year 3: Gift integration (resource)
  → Ready for deepening to systemic level
```

---

## Summary: Player Context Question

**✅ RECOMMENDED APPROACH:**

**Full bidirectional visibility:**
- Players see their full history on every card (Year 1 | Year 2 | Year 3)
- GMs see player history + patterns in GM interface
- Different prompts for each year (surface → shadow → gift)

**Why:**
- Deepening requires context (shows progression)
- Shadow work is intentional (visible transformation)
- Prevents circular repeating (Year 2 ≠ Year 1)
- Builds accountability (player sees growth)
- Enables mastery (visible progression over time)
- Facilitates GM support (GM understands player's pattern)

## Question 4: Facilitation Guidance Detail

**THE QUESTION:** How detailed should GM "Facilitation Notes" be? Should we include what to watch for, what to offer, and group facilitation options?

---

### 🧠 ARCHITECT — Structural Logic

**Assessment:**
More detail = more support, but also more prescription. What's the right level?

**TAKE:**
- **YES, include detailed facilitation notes**
  - What patterns to watch for
  - What to offer if stuck
  - Group facilitation options
- This helps GMs who are new to facilitation
- More experienced GMs can skip notes

**LEAVE:**
- Don't make notes so detailed they're prescriptive
- Don't remove GM's judgment/creativity

**RECOMMENDATION:**
**Include detailed notes with flexibility for GM interpretation.**

Template:
```
FACILITATION NOTES (optional guide, not required script):

WATCH FOR:
  - This card activates [gate name] + [channel name]
  - Common pattern: [what players often do]
  - Signs of shutdown: [what avoidance looks like]

OFFER (if player is stuck):
  - Opening: "What would it take to move anyway?"
  - Deepening: "What part of you is preventing this?"
  - Reframe: "What could this barrier teach you?"

GROUP FACILITATION (if running in circle):
  - Opening: "Who in this room has faced this barrier?"
  - Connection: "What did you discover?"
  - Closing: "What did hearing others' answers illuminate?"

REMEMBER:
  - This is [Year 1/Year 2/Year 3] of this work
  - Trust the player's pace
  - Silence is OK (let them sit with it)
```

---

### 🏛 REGENT — Elegant Preservation

**Assessment:**
GMs are different (new vs experienced, solo vs group, directive vs collaborative). Notes should serve all.

**TAKE:**
- **Multiple facilitation paths**
  - Path 1: Minimal (GM just reads the prompt)
  - Path 2: Guided (GM uses the notes)
  - Path 3: Detailed (GM has options)
- Notes preserve institutional knowledge (what works for this prompt)

**LEAVE:**
- Don't make notes mandatory
- Don't remove GM's flexibility

**RECOMMENDATION:**
**Tiered facilitation notes: Brief | Standard | Detailed.**

Brief (1 line):
```
"This activates Fear + avoidance pattern. Watch for shutdown."
```

Standard (3-5 lines):
```
"Activates Fear gate. Players often intellectualize or avoid.
If stuck, ask: 'What would it take to move anyway?'
Hold the silence. Don't rush."
```

Detailed (full template above):
```
[Full facilitation template with watch-for, offers, group options, remember]
```

---

### ⚔️ CHALLENGER — Critical Edge

**Assessment:**
Facilitation notes should be true/useful. Bad notes are worse than no notes.

**TAKE:**
- **Only include facilitation guidance that's been tested**
  - What patterns actually show up with this prompt?
  - What responses actually help?
  - Don't guess

**LEAVE:**
- Don't include untested theory
- Don't assume one approach works for all

**RECOMMENDATION:**
**Design notes from actual player responses, test and refine over time.**

Process:
```
Year 1 (designing):
  Include "what we think might happen" (provisional)

Year 2 (first players):
  Collect actual player responses
  Update notes based on patterns
  Mark as "tested" or "provisional"

Year 3+:
  Lock in "what actually works"
```

Notes evolve as we learn what actually happens.

---

### 🎭 DIPLOMAT — Bridge & Harmonize

**Assessment:**
Notes should help GMs facilitate connection, not replace human judgment.

**TAKE:**
- **Notes help bridge player experience**
  - "This activates [gate], which often shows up as [pattern]"
  - "If they're stuck, try: [invitation]"
- Notes help GMs validate what they're seeing
- Notes build bridges between individual + group experience

**LEAVE:**
- Don't make notes substitute for GM presence
- Don't prescribe specific language

**RECOMMENDATION:**
**Notes provide framework, not script. GMs adapt to each player.**

Example:
```
FACILITATION NOTES:
"This card often activates the Victim gate (feeling powerless).
Players might respond with: '
I can't change this' or 'It's too big.'

If you notice this pattern, you might say something like:
'I hear that it feels impossible. What would need to be true for you to try anyway?'

Trust your instinct. The goal is presence, not fixing."
```

---

### 🌊 SHAMAN — Shadow & Metaphysics

**Assessment:**
Notes should illuminate shadow work, not hide it.

**TAKE:**
- **Include what shadow this prompt reveals**
  - Which gate activates
  - Which channel emerges
  - What protection is being offered
- Notes help GMs see the gift (not just the wound)

**LEAVE:**
- Don't reduce shadow to pathology
- Don't explain it away

**RECOMMENDATION:**
**Notes name the shadow work explicitly.**

Example:
```
SHADOW ILLUMINATION:
"This prompt activates the Victim gate.
The gift: This gate protects by helping us recognize real powerlessness.
The shadow: It can prevent us from trying.
The work: Acknowledging the protection + choosing to move anyway.

GM note: Help players see 'my Victim part is trying to protect me'
not 'I AM a victim.'"
```

---

### 📖 SAGE — Timeless Principle

**Assessment:**
Mastery comes from practice, not notes. Notes should support practice, not replace it.

**TAKE:**
- **Notes help GMs practice facilitation**
  - "What patterns show up?"
  - "What helps players move?"
  - "What does shadow work look like here?"
- Over time, GMs internalize and don't need notes

**LEAVE:**
- Don't create dependency on notes
- Don't remove GM's need to learn through experience

**RECOMMENDATION:**
**Detailed notes early, GMs drop them as they master the work.**

Example learning curve:
```
GM Year 1: "I read all the notes, follow them closely, learn what happens"
GM Year 2: "I skim notes, mostly use my own judgment, refine my approach"
GM Year 3+: "I rarely check notes, I facilitate from experience"
```

Notes support the learning curve, not replace it.

---

## Summary: Facilitation Guidance Question

**✅ RECOMMENDED APPROACH:**

**Detailed facilitation notes with tiered access (Brief | Standard | Detailed)**

**Includes:**
- What patterns to watch for (gate + channel activation)
- What to offer if stuck (suggested invitations, not scripts)
- Group facilitation options (how to facilitate in circle)
- Shadow illumination (what gift this gate offers)
- Remember notes (permissions + wisdom)

**Why:**
- Supports new GMs (has guidance if needed)
- Respects experienced GMs (can skip notes)
- Documents institutional knowledge (what works)
- Illuminates shadow work (explicitly names the work)
- Supports learning curve (GMs internalize over time)
