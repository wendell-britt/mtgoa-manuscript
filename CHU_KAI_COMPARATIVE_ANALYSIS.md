## Part IV: What MTGOA Does That 10K HP Does NOT

### 1. Emotional Alchemy (MTGOA's Core Unique Contribution)
10K HP does not have an emotional transformation system. It has motivation, momentum, Epic Meaning, but nothing that maps to MTGOA's WAVE framework, 5 elements, and the translation/transcendence mechanic. This is MTGOA's deepest unique layer.

**10K HP has:** Core Drive 4 (Empowerment) and Core Drive 6 (Accomplishment) as motivational poles.
**MTGOA has:** Anger→Creation, Shame→Grace, Grief→Flow, Fear→Presence, Joy→Triumph as a full emotional alchemy cycle with somatic grounding.

### 2. Integral Theory / AQAL Framework
MTGOA is built on Wilber's 4-quadrant model (I/We/It/Its). 10K HP is a personal development framework with no quadrant awareness. This gives MTGOA:
- A way to map allyship efforts across individual, collective, behavioral, and systemic dimensions
- A developmental stage model (Kosice → more advanced)
- A moral center that 10K HP explicitly lacks

### 3. Shadow Work / 321 Method
No equivalent in 10K HP. The 321 (trigger→story→choice) and shadow naming system is MTGOA's inner work technology. 10K HP talks about identity and roles but does not have a structured shadow integration practice.

### 4. Somatic / Nervous System Awareness
MTGOA explicitly engages the body. "The Game Master is in the nervous system." 10K HP is cognitively and motivationally focused. This is a fundamental difference in anthropological model.

### 5. The BARs Engine (Somatic Game as Practice Environment)
10K HP ends at the book. MTGOA has a game engine that can operationalize the framework. The TEAL draft explicitly frames itself as "not a book, it's a game board." 10K HP does not have a gamified practice tool — it's a self-help book with exercises.

### 6. Allyship as a Domain-Specific Practice
10K HP is a general life gamification framework. MTGOA is specifically about increasing well-being in contexts of power imbalance, with 4 allyship domains:
- Gathering Resources
- Direct Action
- Raise Awareness
- Skillful Organising

### 7. Structural racism, capitalism, patriarchy as systemic mirrors
MTGOA explicitly holds that "every structural pattern out there is also mirrored inside your nervous system." 10K HP has no engagement with systemic oppression, power asymmetry, or social justice as a domain of practice.

### 8. Grief and Loss as Core Practice
No equivalent in 10K HP. MTGOA holds grief as a legitimate and necessary emotional pathway, not just something to metabolize.

## Part V: What 10K HP Does That MTGOA Does NOT Need to Worry About

### 1. 10,000 Hours Mastery Tracking
10K HP is literally built around the 10K hours concept. It has detailed:
- Talent Triangles (skill combination mapping)
- Skill Class taxonomy (8 types)
- Role Sphere design (with Career Circles)
- FD Network guild building methodology

**MTGOA recommendation:** Do NOT try to add a "hours tracking" layer. MTGOA is about quality of practice, not quantity. The BARs deck replaces the hour log.

### 2. Career/Professional Identity Architecture
10K HP spends 4+ chapters (2, 3, 4, 6, 7) on professional identity construction:
- Life Game selection (withbadge system)
- Talent Triangles
- 7 Leadership Personas
- Role Sphere and Hero Code
- Factions, Guilds, Parties, Partnerships
- Cold-emailing methodology

**MTGOA recommendation:** Allyship is not a career. Do NOT try to make it one. MTGOA's "Wake Up → Clean Up → Grow Up → Show Up" 4-move structure is simpler and more appropriate.

### 3. SMART Quest + OKR Integration
10K HP Chapter 8 has detailed OKR methodology and SMART quest crafting.
**MTGOA recommendation:** MTGOA's quest grammar is story-driven and somatic, not metric-driven. The BARs engine can have quest completion, but it should NOT become an OKR system.

### 4. Octalysis Framework Core Drive Integration
10K HP is built on Yu-kai's Octalysis Framework (8 Core Drives). This is deep gamification theory that MTGOA references but does not need to replicate.
**MTGOA recommendation:** Reference Octalysis as a citation. Do not try to build it into MTGOA.

### 5. Badge/ Achievement Systems for Life Domains
10K HP has extensive badge taxonomy (Life Game badges, OP Hero Profiles).
**MTGOA recommendation:** The BARs deck IS the badge system. Keep it simple. One deck, unlimited BARs.

### 6. Community Guild Infrastructure (FD Network Model)
10K HP has a full alliance-building playbook with networking tactics.
**MTGOA recommendation:** MTGOA's community is already real (Portland, Vibe Cafe, Bridge Space). Do NOT add a networking automation layer.

### 7. Hero Name / Hero Code Identity System
10K HP has a full identity construction system with public-facing "hero names" and internal "hero codes."
**MTGOA recommendation:** MTGOA has nations, archetypes, and shadow names. Do NOT add a third identity layer.
