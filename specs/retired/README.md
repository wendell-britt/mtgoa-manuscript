# Retired drafts

**Nothing in this directory is canon.** Each file here was superseded by the shipping book and
is kept only because it was the last copy of thinking that took real work to produce.

**Read the note beside a file before using anything in it.** These documents describe an
architecture the book has since moved off, and a reader who takes one at face value will get
the wrong answer. That failure mode is the reason this README exists rather than a bare folder:
this repo has already lost three days to records that asserted a state nobody re-checked.

**Rescued 2026-08-13**, during the branch audit before the twelve remaining branches were
deleted. Both files existed on exactly one branch each, with unrelated history to master.

---

## `APPENDIX_G_BELIEF_TO_SUPERPOWER_MAP.md`

**From `codex/book-eod-draft-2026-06-09`. First drafted 2026-06-10.**

**Superseded because the letter was reassigned.** Appendix G is now
`appendices/ON_THE_SHOULDERS_OF.md`, the bibliography, and has been since the appendix ordering
pass. There is no Appendix G belief map in the shipping book.

**What survives elsewhere:** the belief-to-superpower idea itself is live on master in four
files. It is the specific mapping document that is only here.

**What to check before reusing any pairing in it:** the canonical superpower set is
`specs/CANON_COLLISION_SUPERPOWERS_2026-08-05.md` and the six Face chapters — Alchemist (ch3),
Disruptor (ch4), Storyteller (ch5), Strategist (ch6), Connector (ch7), Escape Artist and Coach
(ch8). A pairing in this draft that disagrees with a chapter is wrong.

## `APPENDIX_H_THE_DECK.md`

**From `simplify-draft-2026-06-08`.**

**Superseded twice over, and the second one matters.**

1. **The letter.** Appendix H is now `appendices/APPENDIX_H_CHARACTER_SHEET.md`.
2. **The architecture.** This draft specs a **52-card deck: four suits on Wake / Clean / Grow /
   Show, thirteen ranks each.** The shipping deck is **120 cards — five moves against four
   domains, run through six operations** — and **seven chapters say so in the body.** The four
   suits also predate Open Up joining the Form, so the spine of this draft is a four-move
   sequence the book no longer has.

**So the card counts, the suit scheme and the move set are all wrong against the book.** What
may still be worth reading is the design reasoning: what a rank is for, how a draw is meant to
feel, why a deck rather than a worksheet.

**Check against:** `ch3:948`'s derivation of the twenty-per-Face grid, `ch1:342`, and the
`decks/` tree, which carries the current specs.
