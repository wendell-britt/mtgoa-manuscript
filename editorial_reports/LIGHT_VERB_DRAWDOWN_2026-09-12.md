## The moves, by weak pattern

- **possession `have/has/had` → a real verb of holding or knowing:** `have the instrument` → *hold*;
  `have a version` (×3) → *carry* / *runs*; `has a consequence` → *carries*; `have the information you
  have` → *know what you know*; `have a position` → *hold*; `have an assessment` → *hold*; `has a
  version` → *runs*; `had continuity` → *endured*; `have the performance of care` → *mime care*; `has a
  direction` → *carries*.
- **causative `make X [adjective]` → the verb doing the work:** `make the inheritance more alive`
  (×2) → *keep alive*; `makes an inheritance transmissible` → *lets pass*; `made accountability real`
  (×2) → *enforced*; `makes the conversion permanent` → *locks in*; `makes precision survivable` →
  *lets survive*; `make/makes coordination possible` (×2) → *let hold* / *lets survive*.
- **`take action` / `make a decision` (the classic delexicals):** `taking/take action` (×4) → *act*;
  `making a decision` (×2) → *decide*.
- **`take X` → a precise verb:** `takes a judgment call` (×2) → *calls for judgment*; `takes an
  inheritance on` → *shoulders*; `take the essence … and make it shorter` → *distill … into something
  shorter*; `takes a situation … have a view about` → *starts from … already judge*; `takes a question
  … returns an answer` → *hears … answers*.
- **`get X` → receive/grasp made explicit:** `getting the argument` → *reading*; `gets/got permission`
  → *counts* / *was allowed*; `getting the movement right` → *right about the movement*.
- **`do/does` (auxiliary in a question) → reworded off the noun:** `does translation end` → *does
  translating end*; `does the balance entitle` → *does staying balanced entitle*; `does the situation
  stabilize` → *does the new game hold you*; `doing detection work` → *that detects*; `do harm` → *cause
  harm*.
- **thematic `perform` → a sharper theatrical verb (contrast kept):** `perform compliance` → *fake*;
  `performs the commitment` → *mimes*; `performing connection, not generating it` → *staging …, not
  generating*; `performing/performed translation/version` → *staging* / *staged*.
- **`give X a shape`** → `shapes`.
