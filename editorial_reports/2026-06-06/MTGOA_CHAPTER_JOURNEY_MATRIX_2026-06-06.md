# MTGOA Chapter Journey Matrix

## Purpose

This matrix maps the five reader journeys onto the eight chapters so each chapter can have:

- one main milestone
- one primary journey
- one main tool
- one clear handoff to the next chapter

The goal is to keep MTGOA layered while preventing each chapter from doing too many jobs at once.

The allyship rule that now governs the whole book is:

> Allyship is relational, consent-based, and trust-earned. You can support a movement, but you only ally with people. Each chapter should define the kind of well-being that matters at that altitude and show how the Effective Allyship Formula serves that form of well-being.

## The five journeys

1. Learning why allyship is wack
2. Learning the game frame and why it helps
3. Building and applying the Effective Allyship Formula
4. Learning the story of how the book came to be
5. Learning how to be allies to the people in your life

## How to read the matrix

- **Primary journey** means the chapter's main job.
- **Secondary journeys** are allowed, but they should support the primary one.
- **Formula step** shows how the Effective Allyship Formula should move through the book.
- **One tool** is the chapter's main usable method.
- **One story/example** should be the strongest human proof.
- **Handoff** should point the reader to the next milestone.
- **Well-being at this altitude** should be read as the chapter's local definition of what "better" means in that Face.

## Drafting rule

If a section does not support the chapter's main milestone, primary journey, or formula step, it should be cut, compressed, or moved elsewhere.

## Special note on Chapter 7

Chapter 7 should remain the clearest proof that the book is not just about better thinking.

It should show:

- how the Sage sees
- how the Sage serves allyship
- how the Sage keeps the formula honest
- how perspective can become a hiding place if it is not tied to action
